# 数据可行性论证报告 (Data Feasibility EDA)

> 前置可行性论证: 从数据源头评估 COAD / READ 两套 TCGA 队列在 WSI-MIL 弱监督任务上的学习信号, 供下游深度学习方向决策, 避免盲目训练。本模块仅做统计与可行性, 不含任何 MIL/Backbone/训练代码。

## 1. 两个队列统计汇总

| 指标 | COAD | READ |
|------|------|------|
| 总样本数 | 321 | 172 |
| 粘液腺癌 (占比) | 48 (15%) | 13 (8%) |
| 死亡事件数 | 50 | 9 |
| 删失率 | 84% | 94% |
| 有完整基因样本 | 321 | 164 |

- COAD 基因表达为 log2 尺度, READ 为原始 TPM (本模块对 READ 做 log1p 后仅用于**队列内**分析)。
- READ 缺少目标基因: OLFM4, DEFA5 (仅 COAD 具备全部 6 基因)。

## 2. 候选任务可行性评估

评级标准: 【推荐】信号强且样本充足; 【谨慎尝试】信号存在但样本/效应量需在图像模型中再验证; 【不建议】信号不足或正例/事件过少。

### 任务A: 粘液分化 PC1 连续回归 (histomolecular)

**COAD — 推荐**  
连续标签可用: PC1 集中 54% 方差, 粘液/非粘液显著分离 (p=1.6e-05, AUC=0.70), 样本 n=321 充足。  

**READ — 推荐**  
连续标签可用: PC1 集中 70% 方差, 粘液/非粘液显著分离 (p=2.8e-06, AUC=0.89), 样本 n=164 充足。  

### 任务B: 粘液腺癌 vs 非粘液腺癌 二分类

**COAD — 谨慎尝试**  
正例 48 个 (15%), 可用但类别不平衡, 需重加权/重采样。  

**READ — 不建议**  
正例仅 13 个 (8%), 正例过少, 深度模型极易过拟合。  

### 任务C: 生存预后 Cox 建模

**COAD — 谨慎尝试**  
事件数 50 (EPV=6.2), 只适合少量协变量的 Cox, 不宜作主任务。  

**READ — 不建议**  
事件数 9 (EPV=1.1), 删失率 95%, 事件严重不足, 仅可作事后附属验证。  


**数据观察 (基因集选择)**: 只保留杯状细胞特异基因 (REG1A/REG4/SPINK4/ITLN1) 做 PCA, 对粘液标签的区分度更高 (OLFM4=肠干细胞、DEFA5=潘氏细胞, 非粘液特异, 会稀释信号)。这与 mucus_mil_regression 现用 4 基因一致。
- COAD: 全基因集 PC1 AUC=0.70 → 核心4基因 (杯状细胞) AUC=0.75, EVR=0.71

## 3. 推荐研究方向

**主推方向 ① — 粘液分化 PC1 连续回归 (双队列)**: 连续标签信号在两队列都存在, 与「WSI 病理弱监督 MIL + Sentinel Patch 采样」主线高度契合 — 图像直接回归分子分化得分, 并可用注意力热力图验证模型是否聚焦粘液/杯状细胞区域。
**辅推方向 ② — 粘液腺癌二分类 (COAD 单队列)**: COAD 正例足够, 可作辅助任务或与回归任务多任务联合; READ 正例过少, 不作训练。
生存任务 (Cox): COAD=谨慎尝试, READ=不建议 — 仅作事后附属验证, 不作深度学习训练目标。

## 4. 风险清单 (深度学习实验需避开的坑)

- **标签泄露**: 分子标签 (PC1/粘液) 由同一张 WSIs 的 RNA 测序得到, 划分 train/val/test 必须按**病人 ID** (同一病人的所有 patch 同折), 且临床/基因特征严禁在划分前用测试集信息。
- **跨队列 PCA 不可混用**: COAD 与 READ 的基因尺度不同 (log2 vs TPM), PC1 必须**各队列独立**拟合; 跨队列统一任务时, 两个队列的 PC1 方向/量纲需对齐说明, 不能共用投影矩阵。
- **EPV 不足 (生存)**: 生存任务 events/predictors 需 ≥10 才稳; READ 仅 9 个死亡事件, 任何生存模型都极易过拟合, 只可作事后验证。
- **高删失**: 两队列删失率均 >80%, KM 尾部置信区间宽, 生存结论需谨慎表述。
- **正例稀少 (二分类)**: READ 粘液仅 13 例, 二分类在 READ 上不可行; 若跨队列统一二分类, 需以 COAD 为主并处理类别不平衡 (重加权/Focal)。
- **标签偏态 (回归)**: PC1 呈右偏 (少数高粘液样本), 直接 MSE 回归会被多数样本主导; 建议排序/相关性 (Spearman) 作为主指标, 并报告 MAE/RMSE 的分组表现。
- **样本量**: 两队列合计 ~480 例, 5 折 CV 下每折测试集 ~30-60 例, 指标方差大, 需报告 mean±std 而非单次。

## 5. 备选叙事方案

### 方案1: 双队列同一任务 (COAD + READ 联合)

**推荐任务: 粘液分化 PC1 连续回归**。两队列都具备该连续标签的学习信号, 可合并扩大样本并验证泛化。实现要点: 各自独立 PCA 得到 PC1 后, 将 PC1 标准化到同一尺度 (如各自 z-score 或统一分箱), 以 COAD 为训练主队列、READ 为跨队列验证队列, 报告两队列各自的 Spearman/MAE。

### 方案2: COAD 为主任务, READ 作对照

以 **COAD** 为主 (样本更多、粘液 48 例、6 基因齐全、事件 50 例), 主任务选 PC1 回归或粘液二分类; **READ** 作为独立外部队列做泛化验证 (仅 PC1 回归可行, 因 READ 粘液仅 13 例、缺 2 基因)。
